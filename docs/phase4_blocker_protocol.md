## Autonomous blocker protocol (Phase 4)

1. Continue reversible independent work whenever possible; do not pause for ordinary choices.
2. For an unavoidable user action (Windows UAC, ROM selection, credential, legal permission, destructive operation), write an exact BLOCKED entry in this checkpoint with the needed action, impact, and safe alternative.
3. Ask once in the progress report, clearly stating what the user must do; do not repeatedly ask or retry an inaccessible approval dialog.
4. Continue a different independent Phase 4 workstream while waiting.
5. On the next scheduled run, re-check whether the blocker is resolved and resume the primary playable milestone.
6. Never assume permission to commit, push, merge, modify proprietary ROM data, or override another agent's work.
